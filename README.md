experiment-oversampling
Replication package for the paper Optimal Split of Real Minority Samples for LLM Oversampling.

This repository contains the implementation, configuration files, and plotting scripts for the allocation experiments in the paper. The experiments study how a scarce real minority sample should be divided between fitting a synthetic generator and training a downstream classifier under strict sample splitting. The synthetic experiments use a controlled Gaussian generator to isolate the statistical effect of the allocation; they are not LLM generations. The real-data experiment uses the Mammography dataset.

Requirements
The code is tested with Python 3.9+. Install the dependencies with:

pip install -r requirements.txt

If requirements.txt is not present, install the core packages directly:

pip install numpy scipy scikit-learn pandas matplotlib

Data
Synthetic Gaussian experiments. The data are generated by the code in src/data/ using the parameters in configs/. No external download is required.

Mammography experiment. The Mammography dataset is not redistributed with this repository. Place the raw file under data/mammography/ and run the preprocessing script, or use the download script if one is provided. Preprocessing follows the paper: PCA to three dimensions and a split of the minority class into classifier-training, generator-fitting, and TV-evaluation subsets.

Reproducing the experiments
All experiments are controlled by the YAML files in configs/. The experiment entry points are in scripts/ (e.g., run_exp1.py, run_real_data.py); each script reads the corresponding configuration file and writes raw outputs to results/raw/. The plotting scripts in scripts/ aggregate the raw outputs and generate the figures in results/figures/.

A typical workflow is:

1. Run an experiment (e.g., Experiment 1)
python scripts/run_exp1.py

Or run all synthetic experiments sequentially
python scripts/run_all.py

2. Aggregate the raw results
python scripts/analyze_results.py

3. Generate the figures
python scripts/plot_exp1.py
python scripts/plot_exp2.py

... run up to plot_exp6.py
For the real-data experiment:

python scripts/run_real_data.py
python scripts/plot_real_data.py

The plotting scripts assume that the corresponding raw results already exist in results/raw/.

Reproducibility notes
Random seeds are set in the configuration files. The synthetic data are generated with numpy.random.default_rng(seed).

The phase-transition and error-floor tables in the appendix report means and standard errors over 30 repetitions.

The Mammography results report means and 95% confidence intervals over 20 repetitions.

The evaluation metric is the balanced risk difference (BRD), defined as the balanced misclassification rate minus 1/2.

The downstream classifier is logistic regression with C = 100, max_iter = 10000, class weights {0: 1.0, 1: 10.0}, and the lbfgs solver.

Scope and limitations
The theoretical results optimize a certified upper bound on the balanced surrogate risk, not the realized risk. The synthetic experiments use a controlled Gaussian generator to validate the allocation theory; they do not claim to reproduce LLM-generated tabular data. The Mammography experiment illustrates the behavior of the allocation rule on a real imbalanced dataset, but it also highlights the difficulty of estimating the generator learning curve from small samples. Future work should validate the rule with actual LLM generators and additional real-world datasets.
